🐳 Docker Interview Questions & Answers
🔹 BASIC DOCKER QUESTIONS
1️⃣ What is Docker?

Answer:
    Docker is a containerization tool. and used deployment process of application.

    When we create an application, it needs:
        Specific language version
        Dependencies
        Sub-dependencies
        Configurations

    If we run the application on another system, there may be:
        Version mismatch issues
        Missing dependencies
        Environment issues
        
    To solve this problem, we use Docker.

    Docker packages the application and all its requirements into a container.
        A container contains:
        Application code
        Dependencies
        Sub-dependencies
        Configurations

    This container can run on any system that has Docker installed.

    No need to install packages or set up the environment again and again.

    The application works the same way on every system.
----------------------------------------------------------------------------------------
2️⃣ What is a Docker Container?

Answer:
Docker Container is created using a Docker Image. 
A Docker Container is the actual running instance of the image. 
When the container runs, the application runs inside it on the system. 
We can start, stop, restart, and delete the container as needed.


in short: Docker Container is the actual running instance of a Docker Image. After creating a container, we can start it, stop it, restart it, check its logs, monitor its status, and execute the application inside it.

Process:

    Docker Image
        ↓
    docker run
        ↓
    Docker Container
        ↓
    Application Running

Remember:

    Container is running.
    We can start, stop, restart, and delete it.
    Multiple containers can be created from one image.
----------------------------------------------------------------------------------------
3️⃣ What is a Docker Image?

Answer:
Docker Image is a template or blueprint. 
It contains all the requirements of an application, such as application code, dependencies, sub-dependencies, libraries, and configurations. 
It is used to create Docker containers. 
The image itself does not run; 
when we run the image, 
Docker creates a container from it.

Process:

    Application Code
        +
    Dependencies
        +
    Configurations
        ↓
    Docker Image

Remember:

    Image is a template.
    Image is not running.
    Image is used to create containers.

4️⃣ Docker vs Virtual Machine?
Docker	                Virtual Machine
Lightweight	            Heavy
Shares host OS	        Own OS
Faster startup	        Slow startup
Less resource usage	    High resource usage.
----------------------------------------------------------------------------------------
5️⃣ What is Dockerfile?
Answer:
A Dockerfile is a text file with set of instructions to build a Docker image.

Dockerfile is a set of instructions used to define the application setup and create a Docker Image using the docker build command.

Example:

FROM node:20-alpine
WORKDIR /app
COPY . .
RUN npm install
CMD ["node", "index.js"]

🔹 NETWORKING & DATABASE QUESTIONS
----------------------------------------------------------------------------------------
11️⃣ How do containers communicate?

Answer:
Containers communicate through a Docker network using service names, not localhost.
----------------------------------------------------------------------------------------
12️⃣ Why localhost doesn't work inside containers?

Answer:
Inside a container, localhost refers to the container itself, not the host or another container.
----------------------------------------------------------------------------------------
13️⃣ How does Node connect to PostgreSQL in Docker?

Answer:
By using the service name defined in docker-compose.yml.

DB_HOST=db
----------------------------------------------------------------------------------------
14️⃣ What is Docker Volume?

Answer:
A Docker volume stores persistent data outside the container lifecycle.
----------------------------------------------------------------------------------------
15️⃣ Why volumes are required for databases?

Answer:
Without volumes, database data is lost when containers restart.
