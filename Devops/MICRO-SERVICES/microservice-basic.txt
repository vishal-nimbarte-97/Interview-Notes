📌 What is a Microservice?

✅Microservices architecture is a collection of services
✅Each service development and deployment is done individually
✅Every service has a different-different task (specific responsibility)
✅It is widely used in e-commerce, logistics, and fintech domains
✅In my current project also, we are using microservices architecture
✅We use different patterns like:
    1.Saga pattern
    2.CQRS pattern
✅I have experience in CQRS pattern
✅In this pattern, read and write services are different
✅Write service is used for POST / create operations
✅Read service is used only for GET / read operations
-----------------------------------------------------------------------------------------------
🔷 Our Architecture Contains:
    
    API Gateway
        It is the entry point
        All client requests come here first
        Handle CORS 

    Write Service (Command Side)
    Handles:
        Create
        Update
        Delete
        Stores data in the write database

    Read Service (Query Side)
    Handles:
        Fetch data
        Uses read database for fast responses
-----------------------------------------------------------------------------------------------
🔷 Simple Flow :-

    🟢 Write Flow
    Client → API Gateway → Write Service → Database

    🔵 Read Flow
    Client → API Gateway → Read Service → Database
-----------------------------------------------------------------------------------------------
📌 Explain your microservice architecture :-

    “My application uses microservice architecture with CQRS pattern. We have an API Gateway as an entry point. The system is divided into Write Service and Read Service. Write service handles create/update/delete operations and stores data in write database. Read service handles queries using a separate read database. We also use Kafka for communication between services and PostgreSQL for data storage.”
-----------------------------------------------------------------------------------------------
📌 How to databases in sync in microservice architecture patter ?

    "In my application, I have three databases: read, write, and audit logs. They are synced using Kafka events. Practically, when I store data in the write database, an event is published to Kafka. That event goes to the read service and audit log service, and then the data is stored in the read database and audit database. In this way, data is synced across all databases.”
