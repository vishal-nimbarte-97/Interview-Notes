*}What is nginx and what is uses of nginx?
-> In my current application, we use NGINX as a reverse proxy. ✅
-> All client requests first come to NGINX instead of directly hitting the backend server. ✅
-> Our backend is horizontally scaled, so we have multiple backend servers. ✅
-> Each backend server contains the same backend code. ✅
-> NGINX is configured as a load balancer. ✅
-> By default, NGINX uses the Round Robin algorithm to distribute requests. ✅
-> All requests do not go to a single server. ✅
-> The load is shared among multiple backend servers. ✅
-> This improves performance, scalability, and high availability. ✅

-> NGINX uses its configuration and algorithm to decide which backend server should handle the request.
-> On the backend side, we use horizontal scaling, which means we have multiple servers.

6. What is Round Robin?
✅Round Robin is the default algorithm in NGINX.
✅It sends requests one by one to different servers.
✅Server 1 gets the first request.
✅Server 2 gets the second request.
✅Server 3 gets the third request.
✅Then it starts again from Server 1.
