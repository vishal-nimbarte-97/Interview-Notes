console.log([] + []);

✅ Output
""
"[object Object][object Object]"


🟦 Case 1: [] + []
Step-by-step:
[]      → ""        // empty array converts to empty string
[]      → ""
"" + "" → ""
✅ Final output:
""

🟦 Case 2: { } + { }
Step-by-step:
{} → "[object Object]"
{} → "[object Object]"
Now JS does:
"[object Object]" + "[object Object]"
✅ Final output:
"[object Object][object Object]"
