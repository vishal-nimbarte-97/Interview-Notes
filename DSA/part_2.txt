45.
for(var i=1;i<=3;i++){
  setTimeout(()=>console.log(i),1000);//3 3 3 
}

Reason :-
This happens because of two things:
var is function scoped (not block scoped).
setTimeout runs asynchronously after the loop finishes.
______________________________________________________________________________________________
46.
for(let i=1;i<=3;i++){
  setTimeout(()=>console.log(i),1000);//1 2 3
}

Reason :-
let is block scoped.
In a for loop, each iteration creates a new block scope, so every setTimeout callback gets its own copy of i.
